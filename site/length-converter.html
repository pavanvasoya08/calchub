About this calculator

This length converter converts values between common units instantly. It also shows the value in every unit at once.

How it is calculated

Each unit is converted through a common base unit: value × (from-unit factor) ÷ (to-unit factor). 1 foot = 0.3048 meters exactly. 1 inch = 2.54 centimeters exactly.

Example

A kilometer is 1,000 meters, and a mile is about 1.609 kilometers.

Frequently asked questions

How accurate is the length converter?

It uses exact or internationally accepted conversion factors, with results shown to several decimal places.

Can I convert in either direction?

Yes. Pick any unit in the From and To lists.
