About this calculator

This tool builds a random password using your browser's cryptographic random number generator. Nothing is stored or transmitted. Longer passwords with more character types are exponentially harder to guess.

How it is calculated

Entropy in bits = length x log2(pool size). With 94 printable characters, a 16-character password has 16 x log2(94), about 105 bits of entropy. Each extra bit doubles the guesses needed.

Example

A 16-character password using all four types draws from 94 characters and has about 105 bits of entropy, which is very strong.

Frequently asked questions

How long should a password be?

At least 12 characters for normal accounts and 16 or more for email, banking and password managers.

Is this generator safe?

Yes. It uses the browser's secure random generator and the password is created on your device only.

Should I reuse passwords?

No. Use a different password for every account and store them in a password manager.
