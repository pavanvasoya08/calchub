About this calculator

Convert kilograms to pounds instantly. Type a value and the result updates as you type. The calculator also shows the reverse conversion and a table of common values.

How it is calculated

Pounds = Kilograms x 2.2046226218. To go back, divide by 2.2046226218.

Example

70 kg = 154.32 lb. And 70 lb = 31.75 kg.

How to use the KG to Pounds Converter

  1. Fill in Kilograms (kg).
  2. Every field starts with an example value. Replace it with your own numbers or keep it to see how the tool works.
  3. Read the result panel. It updates instantly as you type, so there is no button to press.
  4. Change one value at a time to compare scenarios. Nothing is saved or sent anywhere.
