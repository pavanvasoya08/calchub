About this calculator

Pixel density (PPI) tells you how sharp a screen looks. Pick a preset or enter your own resolution and screen size to see the aspect ratio, total megapixels, PPI and the physical width and height.

How it is calculated

Aspect ratio = width : height reduced by their greatest common divisor. PPI = sqrt(width^2 + height^2) / diagonal. Physical width = diagonal x width / sqrt(width^2 + height^2).

Example

A 24 inch Full HD screen has 91.8 PPI, a 16:9 aspect ratio and 2.07 megapixels.

How to use the Screen Resolution Calculator

  1. Fill in Preset, Width (pixels), Height (pixels), Screen diagonal (inches).
  2. Every field starts with an example value. Replace it with your own numbers or keep it to see how the tool works.
  3. Read the result panel. It updates instantly as you type, so there is no button to press.
  4. Change one value at a time to compare scenarios. Nothing is saved or sent anywhere.

Assumptions and limitations

  • Real-world speeds, file sizes and compression vary from the theoretical values used here.
  • Text and password tools run entirely in your browser. Nothing you type is uploaded or stored.

Frequently asked questions

What PPI is good?

Around 100 PPI is comfortable at desktop distance. Phones usually exceed 400 PPI.

What is 16:9?

It means the screen is 16 units wide for every 9 units tall. It is the standard for most monitors and TVs.

Does higher resolution always look sharper?

Only if the screen is large enough or close enough. PPI combines resolution and size.

Is this screen resolution calculator free to use?

Yes. The screen resolution calculator is free, needs no sign-up and runs in your browser, so the numbers you enter are not sent to a server.
