About this calculator

Enter the size of the file and your connection speed to see how long a download will take. The calculator allows for overhead, because real-world speeds are always a little lower than the advertised speed.

How it is calculated

Time = file size in bits / (speed in bits per second x efficiency). File sizes use decimal units: 1 GB = 1,000 MB = 8,000 megabits.

Example

A 5 GB file at 50 Mbps with 90% efficiency takes 14 min 49 s.

How to use the Download Time Calculator

  1. Fill in File size, Size unit, Speed, Speed unit, Efficiency (%).
  2. Every field starts with an example value. Replace it with your own numbers or keep it to see how the tool works.
  3. Read the result panel. It updates instantly as you type, so there is no button to press.
  4. Change one value at a time to compare scenarios. Nothing is saved or sent anywhere.

Assumptions and limitations

  • Real-world speeds, file sizes and compression vary from the theoretical values used here.
  • Text and password tools run entirely in your browser. Nothing you type is uploaded or stored.

Frequently asked questions

How is download time calculated?

Divide the file size in bits by the speed in bits per second. This calculator also applies an efficiency factor for overhead.

Why does the real time differ?

Server limits, Wi-Fi, congestion and the number of devices sharing your connection can slow the download.

Does file size use 1,000 or 1,024?

This calculator uses decimal units (1 GB = 1,000 MB), the same as internet providers.

Is this download time calculator free to use?

Yes. The download time calculator is free, needs no sign-up and runs in your browser, so the numbers you enter are not sent to a server.
