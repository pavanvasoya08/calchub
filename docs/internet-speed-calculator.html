About this calculator

Internet plans are sold in megabits per second (Mbps) but files are measured in megabytes (MB). This calculator converts between them and estimates the time to download typical files, after allowing for protocol overhead.

How it is calculated

1 byte = 8 bits, so MB/s = Mbps / 8. Download time = file size in bits / (speed in bits per second x efficiency).

Example

A 100 Mbps connection is 12.5 MB/s. At 90% efficiency, a 1 GB file takes 1 min 29 s to download.

Frequently asked questions

Why is my download slower than my plan speed?

Wi-Fi quality, server speed, network congestion and protocol overhead all reduce real speed. 85% to 95% of the plan speed is typical.

What is the difference between Mbps and MB/s?

Mbps is megabits per second and MB/s is megabytes per second. One megabyte is 8 megabits.

Is 100 Mbps fast enough?

For most homes, yes. It handles several HD streams, video calls and large downloads at the same time.
