About this calculator

Hexadecimal (base 16) uses the digits 0-9 and A-F. It is widely used for colours, memory addresses and byte values because one hex digit is exactly four bits.

How it is calculated

Decimal = sum of (digit value x 16^position). Hex digits A to F stand for 10 to 15.

Example

FF in hex = 15x16 + 15 = 255 in decimal = 11111111 in binary = 377 in octal.

Frequently asked questions

What does 0x mean?

The prefix 0x marks a hexadecimal number in many programming languages. You can type it or leave it out.

Is the input case-sensitive?

No. ff and FF are the same value.

Why is hex used for colours?

A colour channel has 256 levels, which is exactly two hex digits, so a colour needs six digits such as #FF8800.

Is this hexadecimal converter free to use?

Yes. The hexadecimal converter is free, needs no sign-up and runs in your browser, so the numbers you enter are not sent to a server.
