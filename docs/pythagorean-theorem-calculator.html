About this calculator

The Pythagorean theorem relates the three sides of a right triangle. The hypotenuse is the longest side, opposite the right angle.

How it is calculated

a2 + b2 = c2. To find a leg: b = √(c2 − a2).

Example

If the two legs are 3 and 4, the hypotenuse is √(9 + 16) = 5.

Frequently asked questions

Does this work for any triangle?

No. It only works for right triangles, which have one 90° angle.

What is a Pythagorean triple?

A set of three whole numbers that satisfy the theorem, such as 3-4-5, 5-12-13 and 8-15-17.
