About this calculator

Upload speeds are usually much lower than download speeds, so large uploads such as videos or backups can take a while. Enter your upload speed from a speed test to get a realistic estimate.

How it is calculated

Time = file size in bits / (upload speed in bits per second x efficiency).

Example

A 2 GB video at 20 Mbps upload with 90% efficiency takes 14 min 49 s.

How to use the Upload Time Calculator

  1. Fill in File size, Size unit, Upload speed, Speed unit, Efficiency (%).
  2. Every field starts with an example value. Replace it with your own numbers or keep it to see how the tool works.
  3. Read the result panel. It updates instantly as you type, so there is no button to press.
  4. Change one value at a time to compare scenarios. Nothing is saved or sent anywhere.

Assumptions and limitations

  • Real-world speeds, file sizes and compression vary from the theoretical values used here.
  • Text and password tools run entirely in your browser. Nothing you type is uploaded or stored.

Frequently asked questions

Why is upload speed lower than download speed?

Most home plans are asymmetric and give far more bandwidth to downloads than uploads. Fibre plans are often symmetric.

How do I find my upload speed?

Run an online speed test and use the upload figure it reports.

Can I speed up uploads?

Use a wired connection, pause other uploads and compress the file before sending.

Is this upload time calculator free to use?

Yes. The upload time calculator is free, needs no sign-up and runs in your browser, so the numbers you enter are not sent to a server.
