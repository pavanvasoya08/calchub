About this calculator

This all-in-one unit converter handles eight categories: length, weight, temperature, area, volume, speed, time and data. Pick a category, choose the units and type a value. Use the swap button to reverse the conversion.

How it is calculated

Each value is first converted to a base unit (metre, kilogram, square metre, litre, metre per second, second or byte) and then to the target unit. Temperature uses its own formulas: F = C x 9/5 + 32 and K = C + 273.15.

Example

10 km is 6.2137 miles. 25 °C is 77 °F. 1 GB is 1,000 MB (decimal) or about 0.931 GiB (binary).

How to use the Unit Converter

  1. Fill in Category, Value, From, To, From, To and 12 more option(s).
  2. Every field starts with an example value. Replace it with your own numbers or keep it to see how the tool works.
  3. Read the result panel. It updates instantly as you type, so there is no button to press.
  4. Change one value at a time to compare scenarios. Nothing is saved or sent anywhere.

Assumptions and limitations

  • Conversions use standard factors and are rounded for display. Use more precise figures for engineering or scientific work.
  • Some units (such as gallons or bigha) differ by country or region. The tool states which definition it uses.

Frequently asked questions

Which unit categories are supported?

Length, weight, temperature, area, volume, speed, time and data.

What is the difference between GB and GiB?

1 GB is 1,000,000,000 bytes while 1 GiB is 1,073,741,824 bytes. Operating systems often show GiB but call it GB.

How is temperature converted?

Temperature scales have different zero points, so formulas are used instead of a single multiplier: F = C x 9/5 + 32 and K = C + 273.15.

Are the conversions exact?

Length, weight and volume factors are the exact international definitions. Results are rounded for display.

Is this unit converter free to use?

Yes. The unit converter is free, needs no sign-up and runs in your browser, so the numbers you enter are not sent to a server.
