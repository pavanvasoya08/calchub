About this calculator

Storage makers use decimal units (1 GB = 1,000 MB), while many operating systems report binary units (1 GiB = 1,024 MiB). That is why a 256 GB drive shows as about 238 GB in Windows. This calculator shows how much fits either way.

How it is calculated

Capacity in MB = capacity x (1,000 or 1,024) for GB, and x another 1,000 or 1,024 for TB. Number of files = capacity / file size. Typical sizes: photo 4 MB, song 5 MB, one hour of HD video 3,000 MB.

Example

A 256 GB drive holds about 64,000 photos of 4 MB or 85 hours of HD video in decimal units. In the OS it appears as 238.4 GB.

How to use the Storage Calculator

  1. Fill in Drive capacity, Capacity unit, Unit system, Your own file size (MB).
  2. Every field starts with an example value. Replace it with your own numbers or keep it to see how the tool works.
  3. Read the result panel. It updates instantly as you type, so there is no button to press.
  4. Change one value at a time to compare scenarios. Nothing is saved or sent anywhere.

Assumptions and limitations

  • Real-world speeds, file sizes and compression vary from the theoretical values used here.
  • Text and password tools run entirely in your browser. Nothing you type is uploaded or stored.

Frequently asked questions

Why does my drive show less space than advertised?

Manufacturers count 1 GB as 1 billion bytes, while the operating system counts 1 GB as 1,073,741,824 bytes. Some space is also used by the file system.

How many photos fit in 128 GB?

About 32,000 photos at 4 MB each.

Which unit system should I choose?

Use decimal to match the drive's label. Use binary to match what your computer reports.

Is this storage calculator free to use?

Yes. The storage calculator is free, needs no sign-up and runs in your browser, so the numbers you enter are not sent to a server.
