About this calculator

A Systematic Investment Plan (SIP) invests a fixed amount every month. This calculator estimates the future value for an expected yearly return. You can also add a yearly step-up if you plan to raise your SIP as your income grows.

How it is calculated

Future value = P x ((1+i)^n - 1) / i x (1+i), where P is the monthly amount, i = annual return / 12 / 100 and n the number of months. With a step-up, the monthly amount is raised each year and each month is compounded separately.

Example

A SIP of ₹10,000 a month for 15 years at 12% invests ₹18,00,000 and grows to about ₹50,45,760, so estimated returns are ₹32,45,760.

How to use the SIP Calculator

  1. Fill in Monthly investment (₹), Expected return (% per year), Investment period (years), Yearly increase in SIP (%).
  2. Every field starts with an example value. Replace it with your own numbers or keep it to see how the tool works.
  3. Read the result panel. It updates instantly as you type, so there is no button to press.
  4. Change one value at a time to compare scenarios. Nothing is saved or sent anywhere.

Assumptions and limitations

  • Results use standard formulas and the values you enter. Banks, brokers and tax authorities may apply fees, rounding rules or different compounding, so real figures can differ.
  • Interest rates, tax slabs and investment returns change over time. Market-linked returns (SIP, mutual funds, stocks) are not guaranteed.
  • This tool is for estimation and learning. It is not financial, tax or investment advice.

Frequently asked questions

Are SIP returns guaranteed?

No. Mutual fund returns depend on the market. The calculator shows an estimate based on the return you enter.

What return should I assume?

Equity funds have historically varied a lot. Use a modest, realistic figure and try a few values to see the range.

What is a step-up SIP?

A step-up SIP raises your monthly amount by a fixed percentage every year. Even a 10% increase can add a lot to the final value over a long period.

Is this sip calculator free to use?

Yes. The sip calculator is free, needs no sign-up and runs in your browser, so the numbers you enter are not sent to a server.
