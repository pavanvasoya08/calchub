About this calculator

To write a decimal number in binary, repeatedly divide by 2 and record the remainders. Reading them from last to first gives the binary number. This converter does it instantly and shows the steps.

How it is calculated

Divide the number by 2, note the remainder, and repeat with the quotient until it reaches 0. The remainders read in reverse order form the binary value.

Example

45 / 2 = 22 r1, 22 / 2 = 11 r0, 11 / 2 = 5 r1, 5 / 2 = 2 r1, 2 / 2 = 1 r0, 1 / 2 = 0 r1. Reading the remainders backwards gives 101101.

How to use the Decimal to Binary Converter

  3. Read the result panel. It updates instantly as you type, so there is no button to press.
  4. Change one value at a time to compare scenarios. Nothing is saved or sent anywhere.

Frequently asked questions

How many bits do I need for a number?

A number n needs floor(log2(n)) + 1 bits. For example, 45 needs 6 bits.

Can I convert negative numbers?

Yes, a minus sign is kept and the binary result is shown with a minus sign. Two's complement is not used.

What about decimals like 2.5?

This tool converts whole numbers only.

Is this decimal to binary converter free to use?

Yes. The decimal to binary converter is free, needs no sign-up and runs in your browser, so the numbers you enter are not sent to a server.
