Find the exact number of days, weeks and months between any two dates.

About this calculator

Enter two dates to see the number of days between them, plus the same gap in weeks, months and hours. It also shows which weekday each date falls on.

How it is calculated

Days = end date minus start date. When the box is ticked, one extra day is counted so that both the start and the end date are included. The years, months and days breakdown counts full calendar months.

Example

From 1 January 2026 to 20 November 2026 is 323 days, which is 46 weeks and 1 days.

How to use the Days Between Dates

  1. Fill in Start date, End date, Include the end date in the count.
  2. Every field starts with an example value. Replace it with your own numbers or keep it to see how the tool works.
  3. Read the result panel. It updates instantly as you type, so there is no button to press.
  4. Change one value at a time to compare scenarios. Nothing is saved or sent anywhere.

Assumptions and limitations

  • Dates use the Gregorian calendar and your device's local time zone unless the tool says otherwise.
  • Public holidays differ by country and state, so holiday-based results only count the holidays you enter.

Frequently asked questions

Does the count include the end date?

By default no. Tick the box if you want both dates to be counted, which adds one day.

What if the end date is before the start date?

The calculator swaps the dates for you and shows the gap as a positive number.

Are leap years handled?

Yes. Real calendar dates are used, so 29 February is counted in leap years.

How do I find the number of working days instead?

Use the Working Days Calculator to exclude weekends and holidays.

Is this days between dates free to use?

Yes. The days between dates is free, needs no sign-up and runs in your browser, so the numbers you enter are not sent to a server.
