About this calculator

Convert area from square feet to square metres, which is useful for flats, plots and floor plans. The calculator also shows the reverse conversion and a table of common values.

How it is calculated

Square metres = Square feet x 0.09290304. To go back, divide by 0.09290304.

Example

1,000 sq ft = 92.903 sq m. And 1,000 sq m = 10,763.91 sq ft.

How to use the Square Feet to Square Meter

  3. Read the result panel. It updates instantly as you type, so there is no button to press.
