About this calculator

Convert celsius to fahrenheit instantly. Type a value and the result updates as you type. The calculator also shows the reverse conversion and a table of common values.

How it is calculated

Fahrenheit = Celsius x 9/5 + 32. To go back, Celsius = (Fahrenheit - 32) x 5/9.

Example

25 °C = 77 °F. And 25 °F = -3.89 °C.

How to use the Celsius to Fahrenheit
