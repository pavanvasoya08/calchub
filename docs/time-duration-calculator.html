Find the hours and minutes between a start time and an end time, even when it crosses midnight.

About this calculator

Enter a start time and an end time to see the duration in hours and minutes, in decimal hours and in total minutes.

How it is calculated

Duration = end time - start time. If the end time is earlier than the start time, the calculator assumes the end is on the next day and adds 24 hours.

Example

From 09:00 to 17:30 is 8 hours 30 minutes, which equals 8.5 decimal hours or 510 minutes.

How to use the Time Duration Calculator

  1. Fill in Start time, End time.
  2. Every field starts with an example value. Replace it with your own numbers or keep it to see how the tool works.
  3. Read the result panel. It updates instantly as you type, so there is no button to press.
  4. Change one value at a time to compare scenarios. Nothing is saved or sent anywhere.

Assumptions and limitations

  • Dates use the Gregorian calendar and your device's local time zone unless the tool says otherwise.
  • Public holidays differ by country and state, so holiday-based results only count the holidays you enter.

Frequently asked questions

What if the end time is after midnight?

If the end time is earlier than the start time, it is treated as the next day.

What are decimal hours?

Minutes divided by 60. 8 hours 30 minutes is 8.5 hours.

Can I calculate more than 24 hours?

Use the Date Calculator or Days Between Dates Calculator for longer gaps.

Does it use 12-hour or 24-hour time?

The input follows your device setting and the result uses hours and minutes.

Is this time duration calculator free to use?

Yes. The time duration calculator is free, needs no sign-up and runs in your browser, so the numbers you enter are not sent to a server.
