About this calculator

Paste any text and get it in every common case style. Each result can be copied with one click, which is handy for headings, code identifiers and URLs.

How it is calculated

Title case capitalises the first letter of each word. Sentence case capitalises the first letter of each sentence. camelCase, PascalCase, snake_case, kebab-case and CONSTANT_CASE join the words without spaces.

Example

"convert this Text" becomes CONVERT THIS TEXT, Convert This Text, convertThisText and convert_this_text.

How to use the Text Case Converter

  1. Fill in Your text.
  2. Every field starts with an example value. Replace it with your own numbers or keep it to see how the tool works.
  3. Read the result panel. It updates instantly as you type, so there is no button to press.
  4. Change one value at a time to compare scenarios. Nothing is saved or sent anywhere.

Assumptions and limitations

  • Real-world speeds, file sizes and compression vary from the theoretical values used here.
  • Text and password tools run entirely in your browser. Nothing you type is uploaded or stored.

Frequently asked questions

What is camelCase?

A style where words are joined and each word after the first starts with a capital letter, such as myVariableName.

When should I use kebab-case?

It is common for URLs and CSS class names, for example my-page-title.

Does it change my original text?

No. The original stays in the box and the converted versions appear below.

Is this text case converter free to use?

Yes. The text case converter is free, needs no sign-up and runs in your browser, so the numbers you enter are not sent to a server.
