About this calculator

Type a full expression or use the keypad. The calculator follows the standard order of operations: brackets, powers, multiplication and division, then addition and subtraction.

How it is calculated

Supported: + - * / ^ ( ) ! %, sin cos tan asin acos atan, sqrt cbrt, log (base 10), ln, exp, abs, and the constants pi and e. Example inputs: sin(30), sqrt(144), 5!, 2^10.

Example

2*(3+4)^2 is worked out as 3 + 4 = 7, then 7^2 = 49, then 2 x 49 = 98. In degree mode sin(30) = 0.5.

How to use the Scientific Calculator

  1. Fill in Expression, Angle unit.
  2. Every field starts with an example value. Replace it with your own numbers or keep it to see how the tool works.
  3. Read the result panel. It updates instantly as you type, so there is no button to press.
  4. Change one value at a time to compare scenarios. Nothing is saved or sent anywhere.

Assumptions and limitations

  • The calculator follows standard mathematical definitions. Very large or very small numbers may be shown rounded.
  • Check that your inputs use the units or format the tool asks for (for example, a percentage entered as 12, not 0.12).

Frequently asked questions

Does it follow the order of operations?

Yes. Brackets are done first, then powers, then multiplication and division, then addition and subtraction.

How do I switch between degrees and radians?

Use the angle unit selector. Degrees are the default, which suits most school problems.

What does the ! symbol mean?

It is the factorial. For example 5! = 5 x 4 x 3 x 2 x 1 = 120.

Is this scientific calculator free to use?

Yes. The scientific calculator is free, needs no sign-up and runs in your browser, so the numbers you enter are not sent to a server.
