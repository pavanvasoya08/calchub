About this calculator

Type a full expression or use the keypad. The calculator follows the standard order of operations: brackets, powers, multiplication and division, then addition and subtraction.

How it is calculated

Supported: + - * / ^ ( ) ! %, sin cos tan asin acos atan, sqrt cbrt, log (base 10), ln, exp, abs, and the constants pi and e. Example inputs: sin(30), sqrt(144), 5!, 2^10.

Example

2*(3+4)^2 is worked out as 3 + 4 = 7, then 7^2 = 49, then 2 x 49 = 98. In degree mode sin(30) = 0.5.

Frequently asked questions

Does it follow the order of operations?

Yes. Brackets are done first, then powers, then multiplication and division, then addition and subtraction.

How do I switch between degrees and radians?

Use the angle unit selector. Degrees are the default, which suits most school problems.

What does the ! symbol mean?

It is the factorial. For example 5! = 5 x 4 x 3 x 2 x 1 = 120.
