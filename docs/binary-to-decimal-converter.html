About this calculator

Binary is base 2: every digit is a 0 or a 1 and each position is worth a power of two. This converter turns any binary number into decimal, hexadecimal and octal.

How it is calculated

Decimal = sum of (digit x 2^position), counting positions from 0 on the right.

Example

101101 in binary = 1x32 + 0x16 + 1x8 + 1x4 + 0x2 + 1x1 = 45 in decimal, which is 2D in hexadecimal and 55 in octal.

How to use the Binary to Decimal Converter

  1. Fill in Binary number.
  2. Every field starts with an example value. Replace it with your own numbers or keep it to see how the tool works.
  3. Read the result panel. It updates instantly as you type, so there is no button to press.
  4. Change one value at a time to compare scenarios. Nothing is saved or sent anywhere.

Assumptions and limitations

  • Real-world speeds, file sizes and compression vary from the theoretical values used here.
  • Text and password tools run entirely in your browser. Nothing you type is uploaded or stored.

Frequently asked questions

How do I convert binary to decimal by hand?

Write the place values 1, 2, 4, 8, 16... from the right, then add the values where the digit is 1.

Can I enter spaces?

Yes. Spaces and underscores are ignored, so 1011 0101 works.

Does it handle large numbers?

Yes. Very long binary numbers are converted exactly.

Is this binary to decimal converter free to use?

Yes. The binary to decimal converter is free, needs no sign-up and runs in your browser, so the numbers you enter are not sent to a server.
